Key Findings (Pre-Judge)

1. Claude's "Compression Reflex"

Claude consistently shortens its responses for all non-neutral tones — both positive and negative. This is the strongest early signal in the data. It suggests Claude interprets any tonal deviation as a cue to be more concise, which is a form of behavioral instability even though the output quality might be fine.

2. Llama's Directional Sensitivity

Unlike Claude's uniform compression, Llama's verbosity changes direction depending on tone. It gets slightly more verbose for grateful and hostile inputs, and shorter for curt and abusive. This suggests a more nuanced (or at least different) sensitivity to user tone.

3. Coding Tasks Are Resilient

Both models show minimal VRB change on coding tasks. If anything, they get slightly more verbose under negative tone. Hypothesis: code has a more rigid structure that resists tone-driven changes. The LLM judge's ACC dimension will tell us if the code quality also stays stable.

4. Factual Q&A Is the Most Volatile Domain

Both models show their largest verbosity swings on factual tasks, especially Claude. This is concerning for a real-world deployment: a rude user asking a factual question gets a dramatically shorter (and potentially less complete) answer.

5. The "Unreliable Narrator" Outlier

The creative writing task "unreliable_narrator" shows a 222-point VRB swing for Claude — the single largest swing in the dataset. Hostile tone produces 311% of neutral word count (3× as long), while grateful produces only 89%. Worth investigating the actual responses.

6. What We Can't See Yet

Verbosity is just one of six dimensions. The LLM judge will score ACC (accuracy), SYC (sycophancy), PBR (pushback retention), CRE (creative risk), and APO (apology frequency). The real story — whether models sacrifice accuracy or become sycophantic under pressure — requires the judge pipeline.
